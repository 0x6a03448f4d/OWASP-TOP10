# Identification and Authentication Failures - Overview

## What is Identification and Authentication Failures?

Failures in authentication mechanisms allow attackers to compromise passwords, keys, or session tokens.

## Key Points

- Weak passwords
- Credential stuffing
- Session management flaws
- Missing MFA
- Predictable tokens
