# Vulnerable and Outdated Components - Overview

## What is Vulnerable and Outdated Components?

Using components with known vulnerabilities exposes applications to attacks targeting those specific flaws.

## Key Points

- Outdated frameworks
- Unpatched libraries
- Known CVEs
- End-of-life software
- Missing security updates
