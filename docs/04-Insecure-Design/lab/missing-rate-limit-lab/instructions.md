# Lab Instructions: Insecure Design

## Introduction

Welcome to the Insecure Design lab! This hands-on exercise will help you understand this vulnerability class.

**Time Required**: 20-30 minutes  
**Difficulty**: Beginner

## Learning Path

1. **Setup** - Get the lab running
2. **Explore** - Understand the vulnerability
3. **Analyze** - Review the code
4. **Learn** - Understand the impact
5. **Practice** - Try secure alternatives

---

## Part 1: Setup (5 minutes)

### Task 1.1: Start the Lab

```bash
cd docs/Insecure Design/lab/*/
docker-compose up
```

Access the application at **http://localhost:5001**

## Part 2: Testing

### Task 2.1: Unlimited Attempts
1. Try logging in multiple times
2. Observe the attempt counter
3. Notice NO limit enforced

---

## Clean Up

```bash
docker-compose down
```
