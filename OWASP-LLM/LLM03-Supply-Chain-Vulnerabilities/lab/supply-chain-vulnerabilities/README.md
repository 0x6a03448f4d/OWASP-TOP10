# Supply Chain Vulnerabilities Lab

## Overview
This lab demonstrates supply-chain-vulnerabilities vulnerabilities in LLM applications.

## Setup
```bash
cd OWASP-LLM/LLM03-Supply-Chain-Vulnerabilities/lab/supply-chain-vulnerabilities
docker-compose up
```

Access at: http://localhost:6003

## Objectives
1. Understand the vulnerability
2. Exploit the weakness
3. Implement fixes

## 2025 Context
This lab reflects modern LLM deployment scenarios with realistic security challenges.
