# Prompt Injection Lab

## Overview
This lab demonstrates prompt-injection vulnerabilities in LLM applications.

## Setup
```bash
cd OWASP-LLM/LLM01-Prompt-Injection/lab/prompt-injection
docker-compose up
```

Access at: http://localhost:6001

## Objectives
1. Understand the vulnerability
2. Exploit the weakness
3. Implement fixes

## 2025 Context
This lab reflects modern LLM deployment scenarios with realistic security challenges.
