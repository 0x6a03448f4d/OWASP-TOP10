# Misinformation Lab

## Overview
This lab demonstrates misinformation vulnerabilities in LLM applications.

## Setup
```bash
cd OWASP-LLM/LLM09-Misinformation/lab/misinformation
docker-compose up
```

Access at: http://localhost:6009

## Objectives
1. Understand the vulnerability
2. Exploit the weakness
3. Implement fixes

## 2025 Context
This lab reflects modern LLM deployment scenarios with realistic security challenges.
