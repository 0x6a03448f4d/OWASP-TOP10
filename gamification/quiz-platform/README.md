# OWASP Security Quiz Platform - Professional Edition 🎓

Test and certify your cybersecurity knowledge with our comprehensive, interactive quiz platform!

## 🚀 New Features

### Multiple Exam Modes
- **Quick Quiz** - 5 random questions for fast knowledge checks (~5 minutes)
- **Category Exam** - 15 comprehensive questions per category (~15 minutes)
- **Comprehensive Exam** - 40 questions across all 4 categories (~40 minutes)
- **Custom Exam** - Choose your own categories and create personalized tests

### Enhanced Question Types
- ✅ **Multiple Choice** - Traditional security questions
- ✅ **True/False** - Quick concept verification
- ✅ **Scenario-Based** - Real-world attack scenarios with detailed context

### Professional Features
- 🏆 **Certificates** - Earn digital certificates for scores ≥80%
- 📊 **Progress Tracking** - LocalStorage-based history and statistics
- ⏱️ **Live Timer** - Track your exam completion time
- 💡 **Instant Explanations** - Learn from detailed answer explanations
- 📈 **Statistics Dashboard** - View your performance across categories
- 🔄 **Answer Review** - Detailed post-exam analysis with explanations

## 🚀 Getting Started

1. **Open the Platform** - Click [Quiz Platform](index.html)
2. **Select Your Mode** - Choose Quick, Category, Comprehensive, or Custom
3. **Pick Categories** - Select what you want to test
4. **Take the Exam** - Answer questions with instant feedback
5. **Review Results** - See your score, earn certificates, review answers
6. **Track Progress** - Check your statistics and history
