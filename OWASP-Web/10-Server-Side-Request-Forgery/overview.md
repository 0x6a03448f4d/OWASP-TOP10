# Server-Side Request Forgery (SSRF) - Overview

## What is Server-Side Request Forgery (SSRF)?

SSRF flaws allow attackers to send crafted requests from the server to unintended locations.

## Key Points

- Accessing internal services
- Cloud metadata exposure
- Port scanning
- Bypassing firewalls
- Reading local files
