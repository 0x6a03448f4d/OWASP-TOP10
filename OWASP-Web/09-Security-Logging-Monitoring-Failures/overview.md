# Security Logging and Monitoring Failures - Overview

## What is Security Logging and Monitoring Failures?

Insufficient logging and monitoring allows breaches to go undetected and makes incident response difficult.

## Key Points

- Missing audit logs
- No alerting
- Insufficient log details
- No centralized logging
- Delayed detection
