Vulnerabilities to Find

  1. Mass Assignment: Can you register as an admin?
  2. Admin Endpoint Access: Can regular users access /api/admin/* endpoints?
  3. User Deletion: Can non-admins delete users?
  4. Role Escalation: Can you change other users' roles?
  5. Product Manipulation: Can regular users modify product prices?
  6. Hidden Endpoints: What data is exposed by /api/debug/users?
  7. Settings Access: Can you modify system settings?
  8. Audit Log: Can regular users view the audit log?
