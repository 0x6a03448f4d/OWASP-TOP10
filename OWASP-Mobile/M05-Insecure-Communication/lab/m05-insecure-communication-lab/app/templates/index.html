M05: Insecure Communication

OWASP Mobile Top 10 - Lab Environment

HTTP (INSECURE)

📚 This lab demonstrates how mobile apps expose sensitive data when using unencrypted HTTP instead of HTTPS. All traffic is visible to attackers on the network!

🔓 Vulnerable Login

This form sends credentials over HTTP (unencrypted). Try: alice@example.com / Alice2024!

🔑 API Configuration

Fetch app configuration that contains API keys and secrets over HTTP.

👤 User Profile

Retrieve user profile with sensitive data over HTTP. Token: tok_insecure_alice_12345

💳 Payment Processing

Submit payment information over HTTP (extremely dangerous!).

🚨 Identified Vulnerabilities

  • ✗ Cleartext HTTP: All traffic is unencrypted and visible to network attackers
  • ✗ Credential Exposure: Usernames and passwords transmitted in plain text
  • ✗ API Key Leakage: Secret keys and tokens exposed over HTTP
  • ✗ Payment Data Risk: Credit card information sent without encryption
  • ✗ Session Hijacking: Session tokens can be intercepted and reused
  • ✗ Man-in-the-Middle: Attackers can intercept and modify traffic

📡 Available Endpoints

  • POST /api/login - User authentication
  • GET /api/config - Application configuration
  • GET /api/user/profile - User profile data
  • POST /api/payment - Payment processing
  • GET /api/debug/traffic - View captured traffic
  • GET /api/status - Server status

🔍 How to Intercept

To see what an attacker would capture:

  1. Open browser DevTools (F12) → Network tab
  2. Or use Wireshark / tcpdump to capture traffic
  3. Or set up mitmproxy: mitmproxy -p 8080
  4. Submit forms above and observe cleartext data
  5. Visit /api/debug/traffic to see simulated captured traffic
