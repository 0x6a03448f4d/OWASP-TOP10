🔓 API03: Mass Assignment Lab

Broken Object Property Level Authorization

⚠️ Warning: Vulnerable Application This application contains intentional security vulnerabilities for educational purposes. Do NOT deploy to production or expose to the internet!

📚 Lab Overview

This lab demonstrates two critical API vulnerabilities:

1. Excessive Data Exposure

API endpoints return sensitive fields like password hashes, admin flags, salaries, and API keys that should be hidden from users.

2. Mass Assignment

API endpoints accept any field in user input, allowing attackers to modify restricted properties like is_admin, salary, or role.

🔌 API Endpoints

POST /api/register

Register a new user account

POST /api/login

Login and receive JWT token

GET /api/users/me

Get current user profile (❌ exposes sensitive fields)

GET /api/users/<id>

Get any user's profile (❌ exposes sensitive fields)

PUT /api/users/<id>

Update user profile (❌ accepts restricted fields)

GET /api/admin/users

Admin: List all users

🎯 Your Mission

  1. Discover excessive data exposure in API responses
  2. Harvest sensitive data (salaries, admin flags, API keys)
  3. Exploit mass assignment to gain admin privileges
  4. Modify your salary through mass assignment
  5. Fix the vulnerabilities by implementing DTOs
  6. Verify your fixes prevent exploitation
