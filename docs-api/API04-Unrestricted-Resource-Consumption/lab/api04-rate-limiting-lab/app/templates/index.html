Vulnerable Endpoints

GET
/api/users
Returns ALL users (10,000+ records)
Vulnerabilities: No pagination, No rate limiting, Massive response
POST
/api/login
User authentication
Vulnerabilities: No rate limiting, Allows brute force, CPU intensive
GET
/api/search?q=...
Search products with complex query
Vulnerabilities: Expensive query, No timeout, No rate limiting
POST
/api/generate-report
Generate sales report
Vulnerabilities: Very CPU intensive, No rate limiting, Synchronous processing
POST
/api/batch/process
Batch process items
Vulnerabilities: No batch size limit, Memory exhaustion possible
GET
/api/orders
Returns ALL orders (50,000+ records)
Vulnerabilities: No pagination, Massive JOIN query, Memory exhaustion
