# Attack Scripts

## Overview

These scripts demonstrate various business logic abuse attacks.

## Scripts

1. **bulk_purchase.py** - Purchase entire inventory automatically
2. **coupon_abuse.py** - Stack multiple coupons for maximum discount
3. **reservation_dos.py** - Reserve all inventory to block legitimate users
4. **price_scraper.py** - Extract complete product catalog for competitive intelligence
5. **flash_sale_bot.py** - Instant purchases at machine speed

## Usage

```bash
# Make scripts executable
chmod +x *.py

# Run individual attacks
python3 bulk_purchase.py
python3 coupon_abuse.py
python3 reservation_dos.py
python3 price_scraper.py
python3 flash_sale_bot.py
```

These scripts are for educational purposes only. Use only in the controlled lab environment.
