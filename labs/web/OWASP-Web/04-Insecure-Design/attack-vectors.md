# Insecure Design - Attack Vectors

> **⚠️ EDUCATIONAL PURPOSE ONLY**  
> This document describes attack concepts at a high level for educational purposes.

## Understanding Attack Vectors

Attackers exploit fundamental design flaws that cannot be fixed without redesign.

## Common Attack Patterns

1. **Missing Rate Limiting**: Unlimited brute force attempts
2. **Business Logic Flaws**: Bypassing intended workflows
3. **Missing Security Controls**: No authentication/authorization
4. **Inadequate Segregation**: Mixing roles and permissions
