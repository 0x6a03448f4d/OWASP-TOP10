# Lab Instructions: Security Misconfiguration

## Introduction

Welcome to the Security Misconfiguration lab! This hands-on exercise will help you understand this vulnerability class.

**Time Required**: 20-30 minutes  
**Difficulty**: Beginner

## Learning Path

1. **Setup** - Get the lab running
2. **Explore** - Understand the vulnerability
3. **Analyze** - Review the code
4. **Learn** - Understand the impact
5. **Practice** - Try secure alternatives

---

## Part 1: Setup (5 minutes)

### Task 1.1: Start the Lab

```bash
cd OWASP-Web/Security Misconfiguration/lab/*/
docker-compose up
```

Access the application at **http://localhost:5001**

## Part 2: Testing

### Task 2.1: Trigger Error
1. Click 'Trigger Error'
2. Observe stack trace
3. See exposed file paths

---

## Clean Up

```bash
docker-compose down
```
