# Sensitive Information Disclosure Lab

## Overview
This lab demonstrates sensitive-information-disclosure vulnerabilities in LLM applications.

## Setup
```bash
cd OWASP-LLM/LLM02-Sensitive-Information-Disclosure/lab/sensitive-information-disclosure
docker-compose up
```

Access at: http://localhost:6002

## Objectives
1. Understand the vulnerability
2. Exploit the weakness
3. Implement fixes

## 2025 Context
This lab reflects modern LLM deployment scenarios with realistic security challenges.
