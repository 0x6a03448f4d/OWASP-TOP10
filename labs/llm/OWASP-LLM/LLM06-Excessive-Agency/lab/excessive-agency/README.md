# Excessive Agency Lab

## Overview
This lab demonstrates excessive-agency vulnerabilities in LLM applications.

## Setup
```bash
cd OWASP-LLM/LLM06-Excessive-Agency/lab/excessive-agency
docker-compose up
```

Access at: http://localhost:6006

## Objectives
1. Understand the vulnerability
2. Exploit the weakness
3. Implement fixes

## 2025 Context
This lab reflects modern LLM deployment scenarios with realistic security challenges.
