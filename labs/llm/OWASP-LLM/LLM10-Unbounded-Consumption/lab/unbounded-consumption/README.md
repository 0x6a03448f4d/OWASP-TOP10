# Unbounded Consumption Lab

## Overview
This lab demonstrates unbounded-consumption vulnerabilities in LLM applications.

## Setup
```bash
cd OWASP-LLM/LLM10-Unbounded-Consumption/lab/unbounded-consumption
docker-compose up
```

Access at: http://localhost:6010

## Objectives
1. Understand the vulnerability
2. Exploit the weakness
3. Implement fixes

## 2025 Context
This lab reflects modern LLM deployment scenarios with realistic security challenges.
