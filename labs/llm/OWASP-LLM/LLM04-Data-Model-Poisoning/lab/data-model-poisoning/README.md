# Data and Model Poisoning Lab

## Overview
This lab demonstrates data-model-poisoning vulnerabilities in LLM applications.

## Setup
```bash
cd OWASP-LLM/LLM04-Data-Model-Poisoning/lab/data-model-poisoning
docker-compose up
```

Access at: http://localhost:6004

## Objectives
1. Understand the vulnerability
2. Exploit the weakness
3. Implement fixes

## 2025 Context
This lab reflects modern LLM deployment scenarios with realistic security challenges.
